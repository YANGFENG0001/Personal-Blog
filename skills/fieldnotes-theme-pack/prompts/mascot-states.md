# 看板娘状态图提示词模板

先生成 **idle**，确认形象满意后，再基于 idle 逐个生成其它状态。用支持“参考图 / 图像编辑”的模型时，上传 idle 作为参考图。

## 角色设定（每条提示词开头都带上）

```
原创成年女性角色（22 岁以上），{气质：安静、聪慧、温和}。
{发型发色：长而微卷的深棕色头发，侧边低马尾}，{配饰：深绿色发卡}，{瞳色：棕色眼睛}。
服装：{米白衬衫、深墨绿针织背心、深色长裙}。手持{一本没有任何文字的笔记本}。
画风：{日系动画立绘 / 清爽平涂 / 淡水彩}，干净线稿，柔和光影，光源来自左上方。
```

## idle（默认，必需）

```
{角色设定}
全身立绘，站姿自然，身体微微侧向左侧，视线看向画面左侧，表情温和微笑，双手抱着笔记本。
竖构图 2:3，人物居中，头顶和脚下各留出约 5% 空白，人物完整，不被画面边缘裁切。
纯绿色背景 #00FF00，背景完全均匀，无阴影，无地面，无渐变，人物与背景边界清晰。
不要文字、字母、数字、Logo、水印、签名、边框，不要其他人物。
```

> 角色身上有绿色时，把背景换成 `纯洋红色背景 #FF00FF`。

## 其它状态（基于 idle 修改）

统一前缀：

```
以参考图中的角色为准，保持完全相同的画布尺寸、站位、比例、服装、发型、光源和画风，只修改下面描述的部分。
背景保持纯绿色 #00FF00，无阴影，无文字。
```

| 状态 | 追加描述 |
| --- | --- |
| talk | 嘴巴微微张开像在说话，一只手轻轻抬起到胸前，表情亲切。 |
| happy | 眼睛弯成月牙，开心地笑，脸颊微红，身体稍向前倾。 |
| held | 像被人从后领拎起来：双脚离地微微悬空，手臂向两侧张开，表情惊讶，眼睛睁大，嘴巴呈小小的“o”形。（画布不变，人物整体可以稍微上移） |
| sleep | 闭上眼睛打瞌睡，头微微歪向一侧，笔记本抱在怀里，头顶可以有一个小小的“z”形符号（不是文字字母的风格，而是简笔漫画符号）。 |
| blink | 和 idle **完全一样**，只把眼睛画成闭合的弧线。 |

## 生成后

```bash
# 目录里放 idle.png talk.png …（文件名就是状态名）
node cli.mjs mascot ./我的角色/ 我的角色.mascot.zip --name 我的角色
node cli.mjs check 我的角色.mascot.zip
```

或者打开工作室（`npm start`）逐个拖入，用画笔修补残边，再导出。
