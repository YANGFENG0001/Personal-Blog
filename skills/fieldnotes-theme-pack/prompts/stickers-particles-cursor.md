# 贴纸、粒子、光标提示词模板

## 贴纸合集（一次生成，自动切分）

```
一张素材合集图，1:1，2048×2048。在画面中放置 {6} 个彼此完全分开、互不重叠、四周留有充足间距的独立元素：
{一滴墨水、一枚圆形印章（无文字）、一张撕边纸片、一枚书签、一支铅笔、一个卷起的书页角}。
统一风格：{淡水彩 / 平涂插画}，颜色 {深墨绿、灰黑、纸白、浅木色}，每个元素完整呈现，边缘清楚。
纯绿色背景 #00FF00，背景完全均匀，元素没有投影。
不要文字、字母、数字、Logo、水印。
```

处理：

```bash
node cli.mjs split 合集.png ./stickers/ --kind sticker
```

## 粒子小图（1–4 张）

```
一个单独的 {樱花花瓣 / 枫叶 / 雪花 / 光点}，正面俯视，造型简洁，{颜色}，
居中，占画面约 70%，纯绿色背景 #00FF00，无阴影，无文字。1:1，512×512。
```

处理：

```bash
node cli.mjs matte petal.png petal.webp --kind particle    # 输出 ≤ 64px
```

## 光标

```
一个用作鼠标指针的小图标：{一片叶子 / 一支羽毛笔 / 一颗星星}，尖端指向左上角，
轮廓清楚，配色 {深墨绿与米白}，外圈有 2px 白色描边，以便在任何背景上都看得清。
居中，纯绿色背景 #00FF00，无阴影，无文字。1:1，512×512。
```

处理：

```bash
node cli.mjs matte cursor.png cursor.png --kind cursor    # 输出 32px 的 PNG
```

在主题里写成 `"cursor": { "src": "/uploads/…png", "hotspot": [尖端 x, 尖端 y] }`，坐标按 32×32 计算。
