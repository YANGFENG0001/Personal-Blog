# 背景图层提示词模板

背景要“有意境，但不抢正文”。正文区在画面左侧约 60%，那里要留白、低对比；主体放在右侧或底部。

## 单张背景（日间）

```
用于个人研究博客的横向网页背景，16:9，{2560×1440}。
主题：{晨雾中的苔绿森林边缘，远处湖面与山}。
构图：画面左侧约 60% 是大面积安静留白（{天空 / 薄雾 / 纸面}），细节、对比和视觉主体集中在右侧和底部三分之一。
色彩：{苔绿、木棕、米白、雾蓝}，低饱和，柔和的漫射光，整体偏亮。
风格：{日系动画背景美术 / 淡水彩 / 写实摄影风}，干净，没有噪点。
不要人物、文字、字母、数字、Logo、水印、边框，不要强烈的高光和暗角。
```

## 夜间版本

```
与参考图相同的构图、相同的景物和视角，改为夜晚：
{月光、深蓝天空、少量星星、远处零星暖黄灯光}，整体偏暗但不死黑，左侧正文区保持暗而平。
不要人物、文字、Logo。
```

## 分层（用于视差，效果更好）

分别生成三张同尺寸的图，每张只画一个层次：

| 层 | 描述 | 背景 |
| --- | --- | --- |
| 远景 | 天空与远山 / 远处城市，完整铺满画面 | 不需要透明 |
| 中景 | 只画中景景物（树林 / 房屋 / 山丘），位于画面下半部分 | 纯绿色 #00FF00，用工作室抠图 |
| 前景 | 只画前景的少量元素（草叶 / 枝条 / 栏杆），位于画面底部或角落 | 纯绿色 #00FF00，用工作室抠图 |

在主题里由下往上排列：远景（depth 0）→ 中景（depth 0.15）→ 前景（depth 0.35）。

## 交付

用工作室的“单张素材 → 背景图层”导出 WebP：宽 1920，≤ 400 KB。
