致敬《BEATLESS》（没有心跳的少女）的完整站点主题。**分支 `feat/beatless-lacia`，未合并主线。**

### 背景：为什么之前不像原著

先后做过两版，都不对，原因不同：

- **第一版**是一列深色天际线 + 一座 290 宽的三面体。深色调、随机窗格、没有水——那是
  「赛博朋克通用背景」，换成任何一个 IP 都成立。
- **第二版**把三面体做成贯穿画面的模数化巨构（顶部淡出、等距分缝、收分）。技术上
  「宏伟森严」是做到了，但方向错了：**原著的城市里没有这样一座黑色巨塔**。BLACK
  MONOLITH 是她身后悬浮的装置，大约她自己那么高，是「物」，不是建筑。把它放大成城市
  地标，等于把她随身带的东西复制了一份挂在背景里。

现在按原著的四个特征重画：

1. **滨海城市。** 水面、地平线、大片天空。这是「这是那个地方」最强的线索，前两版一条
   都没有。
2. **玻璃幕墙、横向条带。** 不是冲孔窗，是密集等距的横线。这一条同时解决了可读性：
   等距横条是比随机窗格更低的空间频率，在同等对比度下跟正文抢得少得多。
3. **高架快速路**横穿画面、落在高桥墩上。它是唯一能告诉眼睛「相机比水面高多少」的物体。
4. **高明度配色**——淡蓝、白、一点淡紫。全画唯一的深色是右侧那座棺形剖面的黑塔。

那座黑塔保留了下来，但改了身份：不再是「纪念碑」，而是城市里的一栋黑玻璃楼——
**棺形剖面（顶部两个切角）**是它和角色装置的呼应。切角不是为了好看：68 宽、3 单位收分
的纯矩形在这张图里怎么调色都像滚动条，是那两个肩角让轮廓一眼可辨。

技术约束记两条：

- 顶部淡出必须发生在**场景层内部**。`xMidYMax slice` 下场景层只有 46vh，超出部分不受
  sky 渐变约束——把塔顶放到 `-70` 会在白页面上留一条生硬的灰带。
- 黑塔站在**可读性 veil 之上**（`.scene::after` 给 `z-index: 1`，`.sc-mono` 给
  `z-index: 2`），否则 58% 白 veil 会把 `#151a22` 和 `#28303c` 压成同一个灰。城市留在
  veil 下，主体在 veil 上。近景护栏要压住塔基，所以 `.sc-fg` 是 `z-index: 3`。

## 三、版权边界（重要）

- **主题本身**（配色、字体、场景、彩蛋、文案）是对作品氛围的**致敬**，属于原创设计，不复制任何官方素材。
- **看板娘是原创形象**，只是沿用了「淡紫长发 / 冰蓝眼 / 黑白装 / 黑色秘棺」这套视觉语言，**不是官方立绘的复刻**。`MASCOTS` 里的描述也标了「致敬《BEATLESS》的原创形象，非官方立绘」。
- 仓库里**没有任何官方图片、截图、台本**。
- 如果以后要把站点**公开发布并商业化**，建议把主题名改成更中性的名字（例如「秘棺」「hIE」），避免直接使用作品名作为产品名。

## 四、怎么用 / 怎么撤

### 应用

后台 → **外观与主题 → 主题与配色 → 蕾西亚**。
或直接改设置：

```json
{ "preset": "lacia" }
```

**注意**：如果站点设了「自定义强调色」（`customAccent`），它会**覆盖所有主题的 accent**，蕾西亚主题会变成那个颜色。想看到本色，把强调色清空。

**注意**：如果开了主题轮播（`themeRotation.mode` 不是 `fixed`），轮播会覆盖 `preset`。要么把轮播关掉，要么用站长登录态的 `?theme-preview=lacia`。

### 撤销

```bash
git checkout main          # 代码回到主线（分支保留）
```

主题设置本身存在数据库里，需要单独改回原来的 `preset`。本次验证前的快照在 `.tmp-lacia-backup.json`（未入库）。

## 六、已知限制

- 场景 veil 现在 **58%**（其他场景约 77%）。上一版是 45%——那时需要压得轻，因为黑色巨构在 veil 之下、veil 一重它就变灰。现在黑塔被提到 veil 之上，veil 可以加重，正文更稳，城市仍然读得出来。夜间 72%：再重场景就只贡献 15% 的最终像素，夜城会被抹平。
- 黑塔的位置是被约束出来的：内容列在 1440 视口占 x 160–1280（1080 视口占 48–1032），侧栏「公开统计」的数字落在 x 1044–1280 / y 620–800。黑塔在 veil 之上、接近纯黑，压到这些数字上会直接毁掉可读性，所以它被推到 x 1288–1396 的右侧留白里——1440 下完整，1200 及以下会被 `xMidYMax slice` 裁掉一部分。背景元素被裁是正常的，压文字不是。
- 看板娘是**分层骨架**：30 个语义图层拆自一张立绘，挂在关节上（膝、踝、肘、腕各一级，四条肢体共六段），装置 BLACK MONOLITH 有四种形态。它和小春 / 小晴的**内联 SVG 造型**不是一套实现——那三个是手写 SVG 换形状，这个是真的位图骨架。如果更想要别的立绘，用后台「角色包」导入素材包替换即可，主题的 `mascotPack` 也支持绑定。
- **后台「外观 → 看板娘 → 角色」里那三套「蕾西亚·日常 / 机能 / 礼服」是单张静态立绘**（`mascot_packs` 表里 `daa79f56` / `30db6884` / `09856f59`，各只有一个 `idle` 状态）。选它们会**丢掉分层骨架的全部动画**——它们没有膝、踝、腕，也没有装置联动。要用它们又要有动画，得先用 See-through 重新拆层（ComfyUI 起在 `127.0.0.1:8188`），或者干脆在角色包里再挂一套骨架。
- 场景的六边环只有 3 个（「analog hack」的纹理，不是主角），宽度小于 900px 时整块场景会随移动端布局弱化。
