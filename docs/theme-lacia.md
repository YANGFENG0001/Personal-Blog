### 背景：三版，以及每一版错在哪

先后做过三版，前两版都不对，原因不同：

- **第一版**是一列深色天际线 + 一座 290 宽的三面体。深色调、随机窗格、没有水——那是
  「赛博朋克通用背景」，换成任何一个 IP 都成立。
- **第二版**把三面体做成贯穿画面的模数化巨构（顶部淡出、等距分缝、收分）。技术上
  「宏伟森严」是做到了，但方向错了：**原著的城市里没有这样一座黑色巨塔**。BLACK
  MONOLITH 是她身后悬浮的装置，大约她自己那么高，是「物」，不是建筑。把它放大成城市
  地标，等于把她随身带的东西复制了一份挂在背景里。
- **第三版**（当前）回到「这是那个地方」：高调、大块体量、海湾、水面反光。黑塔删了，
  桥也删了。

现在这张图由四层构成，从后往前：

1. **远岸建筑群**——八个宽窄高矮不一的体量，其中一个明显是塔。第一版这里是循环生成的
   四十个小方块，屏幕上就是一道栅栏；距离感不是靠「很多东西」，是靠「几个很大的东西
   压得很低对比度」。
2. **水面**——148 单位深，中间一条从太阳位置展开的日照路径，越靠近观者越宽越淡，
   上面叠十条横向亮纹。它全画唯一被允许接近纯白。
3. **一艘小船**——28 单位的船体 + 一条横向尾迹。它是唯一告诉眼睛「水面有多大」的东西，
   而代价是三个矩形。
4. **两侧玻璃门柱**——左边两个高度不同的体量、右边一个高的，**都跑出画框顶部**。

三条技术约束，都是踩过才知道的：

- **门柱必须跑出画框。** 停在 y≈92 的体量是「立在地平线上的东西」，画面上方会留一条
  巨大的空白。被顶边裁掉之后，同样的矩形变成墙，中间的空白才读作「空气」。这是这一版
  唯一真正改变观感的一处改动。
- **天空在 SVG 之外。** 场景层是贴底的 46vh 条带，viewBox 里 y≈20 以下已经被建筑挡住
  ——所以 SVG 里画的九团云「看不见」不是 bug，是它们被画在了玻璃后面。上半屏只有
  `.scene` 的 CSS 渐变，要往那里加东西必须用 DOM。现在那里的三条云带是 `.l-bands`。
- **veil 50%（日）/ 66%（夜）。** 上一版需要 58%，因为黑塔在 veil 之下、veil 一重它
  就变灰。黑塔删掉之后 veil 可以更轻，正文反而更稳。夜间曾试过 72% + 近黑天空，结果是
  一个黑色矩形加一个角色：场景贡献不了像素，夜港就只剩概念。66% 配一个真的有地平线
  光晕的天空才留得住它。

**桥为什么被删。** 画过三次：贴着码头（读作路缘）、在 y≈300 横穿（读作横杠）、在 y≈230
横穿（读作平台）。原因不是风格而是结构——水面只有 148 单位深，任何带桥墩的横向桥面都会
把它填满，海湾就不再是海湾。这条比「怎么把桥画好」更值得记。

## 四、怎么用 / 怎么撤

### 应用

后台 → **外观与主题 → 主题与配色 → 蕾西亚**。
或直接改设置：

```json
{ "preset": "lacia" }
```

**注意**：如果站点设了「自定义强调色」（`customAccent`），它会**覆盖所有主题的 accent**，蕾西亚主题会变成那个颜色。想看到本色，把强调色清空。

**注意**：如果开了主题轮播（`themeRotation.mode` 不是 `fixed`），轮播会覆盖 `preset`。要么把轮播关掉，要么用站长登录态的 `?theme-preview=lacia`。

### 撤销

```bash
git checkout main          # 代码回到主线（分支保留）
```

主题设置本身存在数据库里，需要单独改回原来的 `preset`。本次验证前的快照在 `.tmp-lacia-backup.json`（未入库）。

## 六、已知限制

- 场景 veil 现在 **50%（日）/ 66%（夜）**（其他场景约 77%）。第二版要 58%，是因为黑色巨构在 veil 之下、veil 一重它就变灰；黑塔删掉之后 veil 可以更轻，正文反而更稳。夜间试过 72% 配近黑天空，结果是「一个黑色矩形加一个角色」——场景贡献不了像素，夜港就只剩概念。66% 配一个有地平线光晕的天空才留得住它。
- 场景里**没有黑塔，也没有跨海桥**。前者是原著设定（BLACK MONOLITH 是她的装置，不是建筑），后者是结构限制（水面只有 148 单位深，带桥墩的横向桥面会把它填满）。两条都写在 `lacia()` 的注释里，改之前先读那段。
- 画面上半屏是 `.scene` 的 CSS 渐变，SVG 里的东西到不了那里——要往天空加元素只能用 DOM（`.l-bands` 是例子）。
- 看板娘是**分层骨架**：30 个语义图层拆自一张立绘，挂在关节上（膝、踝、肘、腕各一级，四条肢体共六段），装置 BLACK MONOLITH 有四种形态。它和小春 / 小晴的**内联 SVG 造型**不是一套实现——那三个是手写 SVG 换形状，这个是真的位图骨架。如果更想要别的立绘，用后台「角色包」导入素材包替换即可，主题的 `mascotPack` 也支持绑定。
- 骨架现在有**两套皮肤**：战斗服（`suit`）和蓝色连衣裙（`dress`）。两者是同一副 30 层骨架，层数、四类关节、表情矩阵、口型、装置接触全部一致，**换的只是贴图**——不是「降级成静态图」。入口在后台「外观 → 看板娘 → 角色 → 蕾西亚的服装」，主题侧是 `mascot.skin`，代码里是 `src/lib/lacia/rig.ts` 的 `LACIA_SKINS`。
  - 蓝裙的素材在 `docs/seethrough-dress/`（`source.png` + 22 层拆层 + `layers.json`），位图在 `public/lacia-rig/dress/`，几何在 `src/lib/lacia/parts-dress.ts`（**生成物，勿手改**）。改图后重跑 `export_assets.py --src docs/seethrough-dress/layers --meta docs/seethrough-dress/layers.json --name DRESS`。
  - 两套画布 493×1275 / 493×1276，差 1px，肩/髋/脖的**手工枢轴通用**；膝/肘/腕/踝各测各的（关节是身体属性，不是服装属性）。
  - 蓝裙的 `device lock` 挪到了腰带 `[150, 388]`：原位置在战斗服上落在白色髋甲里看不出来，在蓝裙上就是裙摆中部，读作「裙子破了个洞」。
- **后台「外观 → 看板娘 → 角色」里那三套「蕾西亚·日常 / 机能 / 礼服」是单张静态立绘**（`mascot_packs` 表里 `daa79f56` / `30db6884` / `09856f59`，各只有一个 `idle` 状态）。选它们会**丢掉分层骨架的全部动画**——它们没有膝、踝、腕，也没有装置联动。要用它们又要有动画，得先用 See-through 重新拆层（ComfyUI 起在 `127.0.0.1:8188`），或者干脆在角色包里再挂一套骨架。**这就是「服装包」和「皮肤」的区别**：前者是外挂素材，后者是骨架本身多一套贴图。
- 场景的六边环只有 3 个（「analog hack」的纹理，不是主角），宽度小于 900px 时整块场景会随移动端布局弱化。
