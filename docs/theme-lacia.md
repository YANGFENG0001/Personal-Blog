# 蕾西亚主题（`lacia`）

致敬《BEATLESS》（没有心跳的少女）的完整站点主题。**分支 `feat/beatless-lacia`，未合并主线。**

## 四、怎么用 / 怎么撤

### 应用

后台 → **外观与主题 → 主题与配色 → 蕾西亚**。
或直接改设置：

```json
{ "preset": "lacia" }
```

**注意**：如果站点设了「自定义强调色」（`customAccent`），它会**覆盖所有主题的 accent**，蕾西亚主题会变成那个颜色。想看到本色，把强调色清空。

**注意**：如果开了主题轮播（`themeRotation.mode` 不是 `fixed`），轮播会覆盖 `preset`。要么把轮播关掉，要么用站长登录态的 `?theme-preview=lacia`。

### 撤销

```bash
git checkout main          # 代码回到主线（分支保留）
```

主题设置本身存在数据库里，需要单独改回原来的 `preset`。本次验证前的快照在 `.tmp-lacia-backup.json`（未入库）。

## 六、已知限制

- 浅色模式下场景为了压住「黑色秘棺」的观感，veil 透明度调到 45%（其他场景约 77%），所以背景比别的场景**更清楚**——这是有意的，但阅读长文时可能觉得背景更抢眼。夜间原本是 85%，场景只贡献最终像素的 15%，一座本来就暗的夜城被抹平了，所以降到 72%。
- 秘棺的位置是被约束出来的：场景层用 `xMidYMax slice`，1080 宽的视口只露出 x 198–1242，边缘放东西会在某些屏幕上被裁掉；内容列又占了 x 160–1280，比 mid band 更暗的物体放在正文后面达不到 AA 对比度。所以它压在 y=130 以下、落在正文结束之后的那条带里。
- 看板娘是**分层骨架**：24 个语义图层拆自一张立绘，挂在关节上（膝、肘各拆两段），装置 BLACK MONOLITH 有四种形态。它和小春 / 小晴的**内联 SVG 造型**不是一套实现——那三个是手写 SVG 换形状，这个是真的位图骨架。如果更想要别的立绘，用后台「角色包」导入素材包替换即可，主题的 `mascotPack` 也支持绑定。
- 场景的六边环只有 3 个（「analog hack」的纹理，不是主角），宽度小于 900px 时整块场景会随移动端布局弱化。
