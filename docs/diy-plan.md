# 看板娘与全站主题 DIY：优化方案（待审批）

> 状态：草案，等待站主审批。审批前不改代码。

## 0. 现状诊断

我检查了 `素材图/` 和 `data/uploads/` 下的全部 10 张图，结论如下：

| 问题 | 原因 | 影响 |
| --- | --- | --- |
| 看板娘显示成“一张带格子的方图” | 所有“透明 PNG”其实都**没有透明通道**（`hasAlpha=false`），灰白棋盘格是被**画进像素里**的。生图模型常把“透明背景”画成假棋盘格。 | 上传后原样显示，棋盘格和方框都露出来。 |
| 拖动时只是一张图在平移 | 上传图片没有任何处理，也没有为位图做动画、状态和锚点。 | 内置的 SVG 角色能眨眼、跟随视线；位图则完全是死的。 |
| 图片体积大 | 1.4–2 MB 的 PNG 原图直接给访客下载。 | 首屏变慢。 |
| `docs/image-prompts-gpt-image-2.5.md` 要求“真正透明背景” | 这条要求正是假棋盘格的来源。 | 以后生成的素材还会出同样的问题。 |

原型验证：我用“从边缘向内填充、去除中性浅色”的算法试了两张图，大部分棋盘格能去掉。但**被头发包围的棋盘格孔洞**去不掉，边缘还有残留。所以需要更完整的处理流程（见 1.1），再加一个手动修补工具。

## 一、看板娘 DIY 优化方案

### 1.1 上传后的自动处理流程（服务端，使用 sharp）

把图片指定为“看板娘素材”上传时，依次执行：

1. **识别背景类型**：真透明 / 假棋盘格 / 纯色背景 / 复杂背景（复杂背景时提示改用手动或重新生成）。
2. **去背景**：
   - 棋盘格：先自动识别格子的两种灰度和周期（通常 8–32 px），再**全图**匹配这种图案并去除，不只处理与边缘相连的区域，所以发丝间的孔洞也能清掉。
   - 纯色背景：做色键抠图，容差可调。
3. **边缘处理**：
   - 1–2 px 的羽化。
   - 去色溢：消除原背景颜色在边缘留下的灰白或彩色晕边。
   - 去掉孤立的小噪点。
4. **自动裁剪与定位**：
   - 裁掉透明空白。
   - 自动找出“脚底 / 下边缘”作为站立基线。
   - 自动估计头部位置，用来摆放对话气泡。
5. **压缩与派生**：
   - 输出带透明的 WebP，高度上限 720 px，另出一张 2 倍图。
   - 生成缩略图。
   - 典型大小从 1.5 MB 降到约 100–200 KB。
6. **保留原图**：随时可以重新处理。

### 1.2 后台“看板娘工作室”编辑器

- **对比预览**：左边原图，右边处理结果，可以叠在各主题的场景背景上看效果，日间和夜间都能看。
- **修补画笔**：擦除 / 恢复两种画笔，画笔大小可调，专门修自动处理漏掉的孔洞和残边，支持撤销。
- **构图**：
  - 选择显示方式：全身 / 半身（底部渐隐）/ 从屏幕边缘探头。
  - 可调缩放、水平翻转、基线位置。
  - 拖动设置“气泡锚点”，即对话气泡从哪里冒出来。
- **外观**：脚下阴影、描边光晕（让角色在任何背景上都清楚），以及透明度。

### 1.3 让位图“活起来”

位图没法眨眼，所以通过**多张状态图**加**整体动画**来实现：

| 状态 | 何时显示 | 必需？ |
| --- | --- | --- |
| idle 默认 | 平时 | 必需 |
| talk 说话 | 点击 / 弹出气泡时 | 可选 |
| happy 开心 | 彩蛋、读完文章时 | 可选 |
| held 被拎起 | 拖动中 | 可选 |
| sleep 睡觉 | 深夜，或长时间没有操作 | 可选 |
| blink 闭眼帧 | 定时闪一下，模拟眨眼 | 可选 |

缺少的状态会自动回退到 idle。所有状态图都必须同尺寸、同构图，只改表情和手势。技能文档里会规定这一点。

整体动画只用 transform 和 opacity，遵守“减少动态”设置：

- 呼吸：底部固定，轻微缩放。
- 待机：轻微摇摆。
- 点击：轻跳一下。
- 拖动：
  - 拎起时按拖动速度像钟摆一样摆动。
  - 松手后落下，带一次回弹。
  - 靠近屏幕边缘会自动吸附，在边缘时可以切换为探头模式。
- 阴影：随离地高度缩放。

### 1.4 行为与台词

- 每个角色有自己的台词库，可以分组：
  - 时间：早 / 午 / 晚 / 深夜
  - 页面：首页 / 文章 / 404
  - 事件：读完文章 / 彩蛋 / 被拖动 / 回到角落
- 阅读文章时，如果角色挡住正文，就自动缩小或退到边缘。
- 手机端可选一个 48 px 的小头像气泡，代替完全隐藏。

### 1.5 角色包

一个角色是一个“角色包”：状态图 + 锚点 + 台词 + 默认动画参数。可以导入导出 `.zip`，也可以绑定到某个主题。

## 二、全站主题 DIY 方案

### 2.1 主题包（Theme Pack）

每个主题都是一份 `manifest.json` 加一组素材。内置的 12 个主题也改用这个格式，这样任何主题都可以“复制一份再改”。

```
my-theme.zip
├─ manifest.json        # 名称、版本、作者，以及下面列出的所有配置
├─ backgrounds/         # 背景图层（日间 / 夜间各一套）
├─ mascot/              # 角色包（见 1.5）
├─ stickers/            # 装饰贴纸（墨滴、书签、铅笔……）
├─ particles/           # 自定义粒子图（花瓣、叶子……）
├─ cursor/              # 光标图
└─ preview.webp         # 主题卡片封面
```

`manifest` 包含以下内容，每一项都可以在后台图形界面编辑：

| 模块 | 可配置内容 |
| --- | --- |
| 配色 | 日间和夜间各 9 个语义色：背景、表面、正文、次要、弱化、线条、面板、强调、浅强调。 |
| 排版 | 标题和正文字体（系统字体栈，或上传 woff2），字号刻度、行高、字重。 |
| 形状 | 圆角、边框粗细、阴影风格（无 / 柔和 / 纸张 / 浮起）、密度。 |
| 背景 | 最多 6 层，每层可以是图片、渐变、纹理或内置矢量场景；可调位置、尺寸、日夜变体、视差深度、漂移动画、透明度和混合模式。 |
| 阅读保护 | 正文底色的不透明度和模糊；按背景亮度自动算一层遮罩，保证文字对比度。 |
| 粒子 | 类型（飘落 / 上浮 / 闪烁 / 雨 / 烟花），可用内置图形或上传的小图；可调数量、速度、颜色，日夜分别设置。 |
| 装饰贴纸 | 把贴纸放到固定位置：标题旁、卡片角、分隔线、页脚、空状态插画。 |
| 光标、彩蛋、看板娘 | 光标图、彩蛋粒子、绑定的角色包。 |
| 组件风格 | 文章卡片、标签、按钮、分站切换器、代码块，各提供几种预设变体。 |

### 2.2 后台“主题工作室”

- **主题库**：内置主题加我的主题，可以复制、重命名、删除、导入、导出。
- **编辑器**：左侧分区编辑，右侧实时预览。
  - 预览是一个 iframe，显示真实的公开页面：首页、文章页、列表页。
  - 可以切换日间 / 夜间，以及桌面 / 手机尺寸。
- **草稿 → 发布**：
  - 草稿只有站主在预览里能看到，访客看不到。
  - 发布后生效。
  - 保留最近 10 个已发布版本，可以一键回滚。
- **素材自动处理**：去背景、压缩、多尺寸、日夜变体，和 1.1 共用同一套处理流程。
  - 上传的素材包大图会**自动切成**单个贴纸。例如你的“透明素材包”里 8 个元素，会自动切成 8 张贴纸。
- **质量检查**（发布前自动运行）：
  - 文字对比度（WCAG AA）
  - 图片体积和总预算
  - 缺少夜间变体
  - 素材缺少透明通道
  - 正文区域背景是否太花

### 2.3 安全与性能（保持现有标准）

- 主题里**只有数据，没有代码**：不能放 JS，也不能写原始 CSS。所有配置项都经过 Zod 校验，转换成 CSS 变量和预设类名。现有的 CSP 不需要放宽。
- SVG 素材会转成位图后再保存（SVG 里可能藏脚本）。导入 zip 时检查：路径穿越、文件类型（按文件内容识别）、单文件 8 MB 和总量 40 MB 上限。
- 预算：
  - 首屏背景最多 400 KB（WebP，按屏幕宽度提供 1920 / 1280 / 768 三档）。
  - 角色包最多 600 KB。
  - 非首屏素材延迟加载。
- 手机、“动效关闭”或“减少动态”时，视差、漂移和粒子自动降级。

## 三、给其他 AI 用的技能（Skill）

我会写一个技能目录 `skills/fieldnotes-theme-pack/`，你可以复制到 `~/.claude/skills/`，或者直接把内容发给其他 AI。其中：

- `SKILL.md`：什么时候用这个技能；完整的素材规格表（每个位置的用途、尺寸 / 比例、安全区、透明要求、日夜变体）；生成规则；质量检查清单；打包步骤。
- `manifest.schema.json`：主题包格式。生成后可以运行 `npm run theme:check my-theme.zip`，结果和后台导入时的校验一致。
- `prompts/`：每类素材的提示词模板（角色状态图、背景图层、贴纸、粒子、光标、封面），都填好了风格变量。
- `examples/ink-pack/`：用你现有的墨韵素材做成的一个完整参考包。

关键的生成规则（会写进技能里）：

1. **不要让生图模型输出“透明背景”**。应该要求“纯色背景 `#00FF00`，或纯白底，无阴影、无渐变”，再交给本站的处理流程抠图，效果和稳定性都远好于假棋盘格。
2. 同一个角色的各状态图：同画布尺寸、同站位、同光源方向，只改表情和手势；一律不出现文字和水印。
3. 背景图层在正文区域（左侧约 60%）保持低对比，视觉主体放在右侧或底部；日间和夜间各出一张。
4. 原创角色，不使用现成作品里的角色；人物设定为成年。

`docs/image-prompts-gpt-image-2.5.md` 会按上面的规则同步修订。

## 四、实施阶段

| 阶段 | 内容 | 产出 |
| --- | --- | --- |
| P1 | 素材处理流程（去棋盘格 / 色键 / 去色溢 / 裁剪 / 压缩）、看板娘工作室（修补画笔、锚点、预览）、位图状态与动画、台词库 | 你现有的两张角色图能干净地显示，并且有动作 |
| P2 | 主题包格式、内置主题迁移、主题工作室（编辑 / 预览 / 草稿 / 发布 / 回滚）、质量检查、贴纸自动切分、导入导出 | 全站主题可以 DIY |
| P3 | 技能文档 + `theme:check` 命令 + 墨韵示例包 + 修订提示词文档 | 其他 AI 可以按规格产出素材 |

每个阶段结束都会跑完整的测试、截图验收和 Docker 冒烟测试，然后再提交。

## 五、需要你决定的事项

1. **抠图方式**：
   - A：纯算法加手动修补。（推荐）轻量，不增加镜像体积。
   - B：额外加一个 AI 抠图模型（ONNX，约 40–170 MB，每张图在 CPU 上处理几秒）。复杂背景、写实照片效果更好，但镜像变大，VPS 负担也更重。
   - 可以先做 A，以后再加 B。
2. **原始 CSS**：
   - A：不允许。（推荐）只用配置项，安全。
   - B：允许站主写一段自定义 CSS（作为独立文件加载，不放宽 CSP）。灵活，但写错可能破坏页面。
3. **自定义字体上传**：是否允许上传 woff2？字体授权需要你自己负责，中文字体通常有几 MB。
4. **访客能否切换主题**：
   - 现在只有站主能设置主题。
   - 是否允许访客在“已发布主题”之间切换？切换结果会记在 cookie 里，服务端渲染时直接用，不会闪烁。
5. **实施顺序**：是否按 P1 → P2 → P3 进行？还是先做 P3，让其他 AI 先开始产出素材？

## 六、审批结论（2026-10-13）

1. **抠图**：算法和 AI 两种都要，但都放在一个**独立的本地工具**里运行（`tools/asset-studio`），处理好后再上传到网站。后台放这个工具的 git 下载链接，并提示可以用它处理主题素材。网站服务端只做校验，以及“图片没有透明通道”的提醒，不做重度处理。
2. **自定义 CSS**：优先用配置项；主题可以导出为文件，用户自己修改后再导入应用，也可以把这个文件分享给别人来分享主题。导入时做格式检查，避免把页面弄坏。
3. **字体**：允许上传 woff2，并提供常见字体下载网站的跳转链接。
4. **访客不能切换主题**。站主可以设置：主题随机、按计划轮换，以及作为彩蛋在特定条件下切换到某个主题。
5. **顺序**：P1 → P2 → P3。
