# 看板娘素材来源与署名

本站看板娘分两类：

- **原创 SVG 角色**（小春 / 小晴 / 晴见 / 小苔 / 阿星 / 小汐 / Q 版）—— 代码绘制，见 `src/lib/mascot.ts`，无第三方素材，无需署名。
- **网络素材角色包**（小页 / 小葵 / 阿墨）—— 取自开放许可素材站，**必须署名**，说明如下。

# 一、小页

## 来源

| 项 | 内容 |
|---|---|
| 作品 | KUUDERE Visual novel Sprite |
| 作者 | LisadiKaprio |
| 发布页 | https://opengameart.org/content/kuudere-visual-novel-sprite |
| 下载地址 | https://opengameart.org/sites/default/files/kuudere_lisadikaprio.zip |
| 授权 | **CC-BY 4.0** — https://creativecommons.org/licenses/by/4.0/ |

原包内容：7 套服装 × 7 种表情 × 2 个头部角度（HEAD UP / HEAD DOWN），共 112 张透明 PNG（510×1000）。

## 本站如何取用

从原包中选取 **HEAD UP / HEAD DOWN → school uniform（水手服）** 的若干帧，保持原始画布 510×1000，转成 WebP，打包为 `小页.mascot.zip`：

| 状态 | 来源文件 | 效果 |
|---|---|---|
| `idle` | HEAD DOWN / school uniform / smile.png | 低头看书（安静待机） |
| `talk` | HEAD UP / school uniform / smile.png | 抬头看向你（说话） |
| `happy` | HEAD UP / school uniform / smile blush.png | 微笑带红晕（开心） |
| `held` | HEAD UP / school uniform / neutral blush.png | 微红晕（被拖起） |
| `sleep` | HEAD DOWN / school uniform / neutral.png | 低头打盹 + 「Zzz」标记（自制） |

设计思路：原包同一姿势下提供 **低头 / 抬头** 两个头部角度。待机时她低头读书，被点击说话时抬起头——切换状态就会产生「抬头看你」的动效。

## 修改说明（CC-BY 4.0 要求标注改动）

1. **保留原始画布**：510×1000，与原包一致。人物腿部在膝盖以下被原图截断，这是视觉小说立绘的惯例（方便压在对话框后面）；本站看板娘固定在视口底部（`bottom: 0`），截断处正好落在屏幕底边，看不出来。
2. **格式转换**：PNG → WebP（quality 92），单帧约 38–42 KB。
3. **sleep 帧**：在原图上叠加了手绘风格的「Zzz」标记（本项目自制，非原作者素材）。
4. 未改动人物本身，未重新上色。

## 顺带修掉的一处渲染缺陷

`src/styles/mascot.css` 里原本有一条给**旧版单图看板娘**写的规则：

```css
.mascot-btn img { … max-height: 260px; object-fit: contain; object-position: bottom; }
```

角色包的帧图 `<img class="mascot-frame">` 同样命中 `.mascot-btn img`，于是被强行限高 260px 并 `contain` 留白——图片被缩小且左右各空出一截，底部还会离视口底边约 2px，正好把那截断腿露出来。已改为只作用于旧版单图：

```css
.mascot[data-kind='image'] .mascot-btn img { … }
```

改完后角色包按自身比例渲染，尺寸由 `display.height` 决定（当前 220），底部严丝合缝落在视口底边。

## 新增：显示范围（露出到哪一段）

原包里人物只画到小腿，没有脚。为了能自由决定"露出到哪一段"，给角色包的 `display` 加了一个 **`crop`** 字段（0.2–1，默认 1）：

| 值 | 效果 |
|---|---|
| `1`（100%） | 全身——完整画布 510×1000 |
| `0.6`（60%） | 露到腰胯 |
| `0.35`（35%） | 只露头部 |

**缩放保持不变**：降低 `crop` 只是把下半部分裁掉，人物本身不会变小；看板娘固定在视口底部，所以裁得越多，头越贴近屏幕下缘。

改动位置：

- `src/lib/mascot-pack.ts` — `display.crop` 字段（默认 1，老角色包自动取默认值）
- `src/components/public/Mascot.astro` — 输出 `--ms-crop` 变量与 `data-crop` 标记
- `src/styles/mascot.css` — 帧容器按 `--ms-crop` 收窄并 `overflow: hidden`，底部 6% 做渐隐
- `src/components/owner/MascotPacks.tsx` — 角色包编辑器新增「显示范围」滑块，预览实时跟随
- `src/styles/appearance.css` — 编辑器预览的裁切样式

后台路径：**外观与主题 → 看板娘 → 我的角色包 → 小页 → 编辑**，就能看到「显示高度」和「显示范围」两个滑块。

## 署名要求

CC-BY 4.0 要求在**使用处**署名。当前后台「外观与主题 → 看板娘」会显示作者（LisadiKaprio）与授权（CC-BY 4.0）。
若希望在公开页面也明确标注，可在页脚加一行，例如：

> 看板娘形象：LisadiKaprio（CC-BY 4.0）

## 还能做什么

原包还剩 6 套服装（casual / dress / jacket pants / jacket school uniform / jacket skirt / swimsuit）
和 6 种表情（neutral / neutral blush / pissed / smile blush / pervert / super pervert）可用。
想换服装或加「生气」状态，改一下 `mascot.json` 里的取帧即可，无需重新找素材。

> 注意：这套是 **VN（视觉小说）立绘**，原作者在裙摆/大腿处截断，**源包和源 PSD 里都没有脚**。想要"站在地上"的全身角色，用下面的小葵。

# 四、原创 SVG 角色

`src/lib/mascot.ts` 里的 7 个角色全部是代码绘制的原创设计，不含任何第三方素材：

| id | 名字 | 定位 | 绑定主题 |
|---|---|---|---|
| `haru` | 小春 | 樱色发卡、长发、水手服 | 樱花坂 |
| `sora` | 小晴 | 短发侧辫、太阳发夹、透明雨伞 | （可手动选） |
| `harumi` | 晴见 | 双马尾、白裙、雨后初晴、云隙的光 | 晴空之子 |
| `koke` | 小苔 | 苔绿短发、叶形发饰、林间斗篷 | 自然 / 森林 / 草原 |
| `hoshi` | 阿星 | 深蓝短发、星形发夹、高领毛衣 | 星夜 |
| `shio` | 小汐 | 海蓝长发、贝壳发卡、水手领 | 海洋 |
| `chibi` | Q 版 | 最初的 Q 版夏日制服少女 | 夏日物语 |

**晴见**是"致敬《天气之子》氛围"的**原创角色**——只借用"雨、放晴、云隙的光、白裙、双马尾"这些意象，不是任何现成角色的复刻。

设计上四个新角色共用同一套脸部/身体骨架（`bust()` 函数），只替换发色、瞳色、后发轮廓、服装与配饰，所以站内风格统一；配饰/配色按主题气质设计，切到对应主题时角色与背景是协调的。
