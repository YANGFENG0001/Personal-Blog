贴纸、粒子、光标、背景等。贴纸“合集图”可以自动切成单张。

为什么上传的“透明图”还是一个方块？

很多生图模型会把“透明背景”画成一张灰白棋盘格的图片，看起来透明，其实每个像素都是不透明的。网站拿到它只能原样显示。本工具会识别这种假棋盘格并把它去掉。

推荐的生图方式

  1. 不要要求“透明背景”。改为：纯绿色背景 #00FF00，无阴影，无渐变，人物与背景边界清晰（人物身上没有绿色时）或纯白背景。
  2. 同一个角色的所有状态图：同尺寸、同站位、同光源，只改表情和手势。
  3. 把图拖进本工具 → 检查 → 用画笔修补 → 导出角色包。

AI 抠图

算法处理不了的复杂背景（照片、场景插画）需要 AI 模型。首次使用会下载模型到 ~/.fieldnotes-studio/models（国内自动走镜像）。需要先在本目录运行 npm install（会安装 onnxruntime-node）。

隐私

本工具只在你的电脑上运行（127.0.0.1），图片不会上传到任何地方。
